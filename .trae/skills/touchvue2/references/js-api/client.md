# 终端检测
获取终端的信息。

## 属性

| 方法              | 方法返回值为 true 时对应的浏览器 |
| ----------------- | -------------------------------- |
| $.browser.msie    | IE浏览器                         |
| $.browser.mozilla | Firefox浏览器                    |
| $.browser.opera   | Opera浏览器                      |
| $.browser.webkit  | Safari 或 Chrome浏览器           |
| $.browser.safari  | Safari浏览器                     |
| $.os.phone        | 是否手机客户端                   |
| $.os.pad          | 是否平板客户端                   |
| $.os.android      | 是否安卓客户端                   |
| $.os.iphone       | 是否iPhone客户端                 |
| $.os.ipad         | 是否iPad客户端                   |
