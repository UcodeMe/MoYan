# 提示（c_tip）
以文字的方式描述希望使用者重点关注的信息，属于事前提醒。 

## HTML

<a href="#/example/component/tip" target="_blank">查看演示</a>

```html
<div class="c_tip">提示文字</div>
```

## 样式

| 参数名      | 值  | 默认值 | 描述     |演示     |
| ----------- | -------- | ------ | -------- |--- | 
| c_tip-red   | c_tip-red<br />c_tip-green<br />c_tip-orange<br />c_tip-blue<br />c_tip-ob（白色/反色） | 无     | 设置颜色 ||
| c_tip-float | c_tip-float  | 无     | 设置悬浮 ||
| c_tip-outline | c_tip-outline  | 无     | 外边线 |<a href="#/example/component/tip-outline" target="_blank">查看</a>|
| c_tip-outline-dashed | c_tip-outline-dashed  | 无     | 虚线 |<a href="#/example/component/tip-dashed" target="_blank">查看</a>|
