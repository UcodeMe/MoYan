# 菜单（c_menu）
支持多级显示的站点地图功能。

## HTML

<a href="#/example/component/menu" target="_blank">查看演示</a>

```html
<div class="c_menu">
	<div class="title">菜单类标题</div>
	<div class="menu menu-col-3">
		<ul>
			<li>菜单</li>
		</ul>
	</div>
	<div class="leaf">子菜单类标题</div>
	<div class="menu menu-level-2 menu-col-3">
		<ul>
			<li class="on">菜单</li>
		</ul>
	</div>
</div>
```
