# 元素间距（e_space）
内联元素之间的横向距离。 

## HTML
<a href="#/example/element/space" target="_blank">查看演示</a>
```html
<span class="e_space"></span>
```

## 样式

| 参数名           | 值                                                   | 默认值  | 描述         |
| ---------------- | ---------------------------------------------------- | ------- | ------------ |
| e_space-2        | e_space<br />e_space-2<br />e_space-3<br />e_space-4             | e_space | 大小设置     |
| e_space-c        | e_space-c                                            | 无      | 紧凑         |
