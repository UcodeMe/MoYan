# 标签（e_tag）
标签一般隶属某主体内容，其内容是对主体内容性质或状态的精简描述。

## HTML
<a href="#/example/element/tag" target="_blank">查看演示</a>
```html
<span class="e_tag">文字</span>
```

## 样式

| 参数名     | 值           |  默认值 | 描述     |演示     |
| ---------- | ------------ | ------ | -------- |------- |
| e_tag-blue |e_tag-blue<br />e_tag-green<br />e_tag-orange<br />e_tag-red|  无     | 颜色设置 ||
| e_tag-s |e_tag-s | 无 | 小版本 ||
| e_tag-r |e_tag-r |  无     | 数值提示形态 |<a href="#/example/element/tag-num" target="_blank">查看</a>|
| e_tag-outline |e_tag-outline | 无 | 外边框 |<a href="#/example/element/tag-outline" target="_blank">查看</a>|
| e_tag-outline-dashed |e_tag-outline-dashed | 无 | 虚线 |<a href="#/example/element/tag-dashed" target="_blank">查看</a>|
