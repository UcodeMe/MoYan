# 手机端和PC端如何分别定义样式

## 场景分析
在不同的业务之中，需求某个样式仅在适应PC端或移动端时生效的场景，因此我们就需要为其定义样式。

## 原理

在页面渲染之前，我们用 JS 对 页面进行了判断，当高度小于/大于宽度时就适应 PC/移动端样式，同时给 ``<html>`` 标签加了 s_pc/s_phone 的样式名，例：``<html class="s_pc"></html>``,因此写在s_pc/s_phone 类名下的样式各自生效。

## 定义方式

PC端
.s_pc .myClass { ... }


移动端
.s_phone .myClass { ... }
