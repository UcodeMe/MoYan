# 表头错位了怎么办

## 问题现象

表格出现了重复的表头，并且有些数据挤在左上角，大概是这样子：

![tableCollpase](../static/img/doc/theadCollpase.png)

## 原因分析

由于 @Table 组件默认是支持固定表头的，固定表头的原理是通过复刻表头并展示在一个与表格本身没有直接关系的新的 ``div`` 中，从而不受到滚动条的影响，而这个表头的“复刻”过程，需要获取原表格的尺寸数据，比如高度、宽度等。如果原表格默认是隐藏的，获取到的尺寸会都变成 0，所以就会出现以上现象。

## 解决方法

### 方法一：不使用固定表头

给表格设置 ``fixedMode="false"``。

### 方法二：手动调整

在表格显示之后，执行相关 API 重新获取表格的数据。

```js
$("#hiddenDiv").show();
myTable.adjust();
```
