## 样式

| 参数名     | 值           |默认值 | 描述     |
| ---------- | ------------ | ------ | -------- |
| e_size-s |e_size-x<br />s e_size-s<br /> e_size-m<br /> e_size-l<br /> e_size-xl<br /> e_size-xxl<br /> e_size-xxxl<br /> e_size-xxxxl |  无     | 大小设置 |
| e_red |e_red<br />e_blue <br />e_green <br />e_orange <br />e_navy <br />e_navy-lighter <br />e_gray <br />e_gray-light <br />e_black <br />e_black-light <br />e_white | 无 | 色彩设置 |
| e_strong |e_strong |  无     | 加粗 |
| e_sup |e_sup |  无     | 上标 |
| e_delete |e_delete |  无     | 删除（删除线） |
| e_explain |e_explain |  无     | 解释说明 （class="e_explain" title="解释说明"） |
