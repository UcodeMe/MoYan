# 标记（e_label）
用于标记一定对象的辅助信息，比如单位、前缀等。

## HTML
<a href="#/example/element/label" target="_blank">查看演示</a>
```html
<span class="e_label">标记</span>
```

## 样式

| 参数名     | 值           |  默认值 | 描述     |演示     |
| ---------- | ------------ | ------ | -------- |-------- |
| e_label-blue |e_label-blue<br />e_label-green<br />e_label-orange<br />e_label-red<br />e_label-navy<br />e_label-yellow |  无     | 色彩设置 |<a href="#/example/element/label-color" target="_blank">查看</a>
| e_label-s |e_label-s<br />e_label-m<br />e_label-l | e_label-m | 大小设置 ||
| e_label-r |e_label-left<br />e_label-right<br />e_label-r |  无     | 圆角设置 |<a href="#/example/element/label-r" target="_blank">查看</a>
