# 图片
控制图片的外观。

## HTML
<a href="#/example/element/pic" target="_blank">查看演示</a>
```html
<span class="e_pic">
	<img src="images/avatar.png" alt="用户头像" />
</span>
```

## 样式

| 参数名     | 值           |默认值 | 描述     |演示|
| ---------- | ------------ | ------ | -------- |------|
| e_size-r |e_pic-r |  无     | 圆角设置 |<a href="#/example/element/pic-r" target="_blank">查看</a>|
| e_pic-square-x |e_pic-square-x| 无 | 按x轴方向裁剪 |<a href="#/example/element/pic-square-x" target="_blank">查看</a>|
| e_pic-square-y |e_pic-square-y| 无 | 按y轴方向裁剪 |<a href="#/example/element/pic-square-y" target="_blank">查看</a>|
| e_pic-square-5 |e_pic-square-5～e_pic-square-10| 无 | 裁剪大小设置 |<a href="#/example/element/pic-square-5" target="_blank">查看</a>|
