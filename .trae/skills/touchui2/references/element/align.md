
# 对齐（e_left）

对齐方式是指子元素在父元素中的相对位置。 

## HTML
<a href="#/example/element/align" target="_blank">查看演示</a>
```html
<td class="e_left">子元素水平左对齐</td>
```

注意：此元素需用在，应对齐元素的父级。如 div，table，p，input，td... 		

## 样式

| 参数名     | 值           |  默认值 | 描述     |
| ---------- | ------------ | ------ | -------- |
| e_right |e_right |  无     | 子元素水平右对齐 |
| e_left |e_left |  无     | 子元素水平左对齐 |
| e_center |e_center | 无 | 子元素水平居中对齐 |
