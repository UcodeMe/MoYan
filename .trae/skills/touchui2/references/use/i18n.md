# 国际化支持



## 功能定义

这里的国际化支持是指基于 Touch UI 前台框架的 web 应用，能在运行时根据不同语言使用者的需要，对同一个页面能够同时支持多种语言来做展示。


## 功能设计

### 设计约束

WEB 应用的文本字符集，包括 HTML, JS 脚本，Java 代码，以及各种文本配置文件，必须统一使用 UTF-8 字符集格式编辑和存储，以确保其对多语言内容的支持。

WEB应用运行时必须使用 UTF-8 字符集，包括中间件的 web 应用字符编码配置，JDK 的环境变量配置等，以确保应用运行时能正确解析 UTF-8 字符内容。

涉及不同语言文本存储的数据库表字段必须使用支持多语言的字段类型。

该部分设计不包括动态内容（主要是数据库存储的业务数据、缓存中的业务数据等）的国际化支持设计实现。

### 在会话中存储国际化标识

会话中使用标准 HttpSession 接口来存储国际化（语言地区类型）标识，键名为不重复的 Session 键，键值为语言地区标识字符串，格式为 “语言小写_地区大写”，例如： 中文中国(zh_CN)， 中文台湾(zh_TW)，中文香港(zh_HK)，美国英语(en_US)等。

在切换会话语言时，需要将会话 Session 中的语言类型标识设置为对应值，并重新加载界面。

### 框架界面和 UI 组件国际化
#### 后端
**框架界面和 UI 组件在运行时通过从会话中获取的不同的语言类型标识，来显示从配置文件中加载的不同语言的文本资源内容，实现不同的语言界面和 UI 的展示，包含以下关键点：**

1. 框架国际化资源以配置文件的形式打包在框架 jar 包中，配置文件中以键值对的形式存储国际化文本编码和对应内容

2. web 应用启动时，框架从配置文件中加载国际化资源到JVM缓存中，每个语言类型的资源内容存储在一个哈希表中，哈希表的键名为国际化文本编码，键值为该文本编码对应语言类型的文本内容。

3. web 应用运行时，根据会话中的当前语言类型标识和某个位置需要显示的文本编码，从框架国际化资源缓存中对应语言类型的哈希表中获取对应文本编码的内容进行显示。

#### 前端

框架前端相关国际化资源通过 JSON 数据方式定义，保存在不同的 js 文件中，每个语言类型维护一个 js 文件。JSON 中，键名为国际化文本编码，键值为对应文本内容。

后端 web 应用根据会话中的不同语言类型标识，生成对不同资源 js 文件的 script 引用标签返回给客户端浏览器，客户端浏览器解析后加载对应语言类型的 JSON 数据，用于框架前端程序中。

### 业务界面和UI组件国际化

业务界面的国际化资源统一存储在数据库表配置中，表设计如下：

![IE8IconPosition](../static/img/doc/i18n.png)


 其中：

资源地区   -  国际化语言地区标识，即前文所说的 “zh_CN”、"en_US"

资源类别   -   国际化资源的使用类别，用以区分用在后端还是前端，取值：0 - 后端, 1 - 前端 

资源标记   -   国际化资源的标记，用以区分不同页面或组件的国际化资源

资源编码   -   国际化资源的编码，用以标识不同的资源内容

资源内容   -   国际化资源的文本内容，该字段需要支持不同语言文本的存储。

当WEB应用启动时，按照：资源类别  ->  资源地区 -> 资源标记 的三层MAP结构，将数据库表的数据缓存到本地应用进程的 JVM 缓存中，提供给运行时使用。

#### 后端

业务界面后端使用国际化资源 JWC 组件来用以在 Tapestry 动态页面模板或组件模板上显示不同的语言内容，该组件由业务层框架提供，并通过访问应用进程中的国际化资源本地 JVM 缓存来获取国际化资源文本内容，JWC 组件通过传入资源编码来指定需要显示的资源文本，例如：

```html
<span jwcid="@biz:I18nResource" code="changeproduct.btn-submit-text"></span>
```

组件在获取国际化资源时，默认使用组件所在的容器组件类路径作为资源标记，也可以通过组件参数指定不同的资源标记，例如：
```html
<span jwcid="@biz:I18nResource" sign="com.ai.nj.i18n.test.Test" code="changeproduct.btn-submit-text"></span>
```

#### 前端

业务界面前端国际化资源通过一个通用的 HttpHandler 类来加载，业务界面在向客户端返回页面内容时，将该 HttpHandler 的引用通过 &lt;script&gt; 标签插入到页面 HTM L结构里，并在 HttpHandler 的访问 URL 里拼入当前页面的页面类路径作为资源标识参数。客户端加载页面时，访问该 HttpHandler 加载该页面相关的前端国际化资源，例如：

```html
<script type="text/javascript" src="handler?clazz=com.ailk.biz.view.handler.I18nResourceHandler&method=init&sign=com.ai.touch.touchframe.view.frame.pc.Login"></script>
```
HttpHandler 根据传入的资源标识，从国际化资源缓存中将该资源标识相关的所有国际化资源键值对以 JSON 数据的方式返回给前端。前端应用程序将返回的 JSON 保存，并通过框架提供的公共API进行访问。

### 异常信息和接口调用国际化

WEB 应用的异常信息统一在框架异常解析接口实现类中处理，异常信息的国际化需要在异常解析类中的解析逻辑里结合当前会话中的国际化标识来将异常编码翻译成不同语言的异常信息。需要在现有的异常解析逻辑上进行改造。

WEB 应用调用后端服务接口时，将当前会话中的国际化标识作为接口调用的上下文参数传入，为后端服务处理国际化相关逻辑提供标识字段。

## 功能实现
### 在会话中存储国际化标识

前台界面的切换语言功能中，使用标准语言地区标识作为选项值：

```html
<select name="LOCALE">
	<option value="zh_CN">中文中国</option>
	<option value="zh_TW">中文繁体</option>
	<option value="en_US">美国英语</option>

```

当用户切换语言时，将切换后的值存储在会话中：

```java

session = request.getSession(true);
session.setAttribute("LOCALE",  request.getParameter("LOCALE"));
```

框架的 ``com.wade.web.lang.Lang`` 类负责保存当前请求线程的国际化标识 ：
```java
private static ThreadLocal<Locale> _locale = new ThreadLocal<Locale>();

public static Locale getLocale(){
	Locale locale = _locale.get();
	if( locale != null && !"".equals(locale) ){
		return locale;
	}
	return DEFAULT_LOCALE;
}

public static void setLocale(Locale locale){
	if( locale != null && !"".equals(locale.toString()) 
	   && data.containsKey(locale.toString()) ){
		_locale.set(locale);
	}
}

public static void setLocale(Object localeObj){
	if(localeObj != null){
		Locale locale = null;
		if( localeObj instanceof String ){
			locale = Locale.forLanguageTag( (String)localeObj );
		}else if( localeObj instanceof Locale ){
			locale = (Locale)localeObj;
		}

		if( locale != null ){
			setLocale(locale);
		}
	}
}
```

```javascript
Wade.lang = {
	get: function() {
		var args = arguments;
		var key = args[0];
		if (!key || !Wade.isString(key)) return;
		var val = Wade.lang[key];
		if (val && Wade.isString(val)) {
			if (args.length > 1) {
				val = val.replace(/\{(\d{1})\}/gi, function(m) {
					var mt = m.match(/\{(\d{1})\}/i);
					if (mt && mt.length == 2) {
						return args[mt[1]] ? args[mt[1]] : "";
					}
					return m;
				});
			}
			return val;
		}
	},
	extend: function(val) {
		Wade.extend(Wade.lang, val);
	}
};
```

```java
public IData loadJavaI18nResource() throws Exception{
	I18nResourceDAO dao = DAOManager.createDAO(I18nResourceDAO.class, "CEN1");
	IData map = new DataMap();

	/**
	* 按照结构层级存储
	*/
	IDataset ds =  dao.loadJavaI18nResource();
	if(ds != null && ds.size() > 0){
		IData data = null;
		String locale = null, sign = null, code = null, content = null;
		for(int i = 0, size = ds.size(); i < size; i ++){
			data = ds.getData(i);
			locale = data.getString("RES_LOCALE");
			sign = data.getString("RES_SIGN");
			code = data.getString("RES_CODE");
			content = data.getString("RES_CONTENT");

			IData localeData = null;
			if(locale != null && !"".equals(locale)){
				locale = locale.toUpperCase(); // 需要统一转换为大写
				localeData = map.getData(locale);
				if( localeData == null ){
					localeData = new DataMap();
					map.put(locale, localeData);
				}
			}

			IData signData = null;
			if(sign != null && !"".equals(sign)){
				signData = localeData.getData(sign);
				if( signData == null ){
					signData = new DataMap();
					localeData.put(sign, signData);
				}
			}

			if( code != null && !"".equals(code)) {
				signData.put(code, content);
			}
		}
	}

	return map;
}
```

com.ailk.biz.util.I18nUtil 类实现国际化资源的工具类封装，如下：：
```java
public final class I18nUtil
{

	private static IReadOnlyCache javaI18nResourceCache = null;
	private static IReadOnlyCache jsI18nResourceCache = null;

	private static transient final Logger log = Logger.getLogger(I18nUtil.class);

	static {
		try {
			javaI18nResourceCache = CacheFactory.getReadOnlyCache(JavaI18nResourceCache.class);
			jsI18nResourceCache = CacheFactory.getReadOnlyCache(JsI18nResourceCache.class);
		}catch (Exception e) {
			log.error("加载I18nResourceCache异常", e);
		}
	}

	private I18nUtil(){

	}

	/**
	 * 获取地区为 locale 的同一 sign 标识的 Java 国际化资源合集
	 * @param locale
	 * @param sign
	 * @return
	 * @throws Exception
	 */
	public static final HashMap getJavaI18nResource(Locale locale, String sign) throws Exception{
		if(null == javaI18nResourceCache)
			return null;
		if(null == locale)
			return null;
		if(null == sign || "".equals(sign))
			return null;

		HashMap localeMap = (HashMap)javaI18nResourceCache.get(locale.toString().toUpperCase());
		HashMap signMap = localeMap != null ? (HashMap)localeMap.get(sign) : null;

		return signMap;
	}

	/**
	 * 获取地区为 locale、标识为 sign、编码为 code 的 Java 国际化资源文本
	 * @param locale
	 * @param sign
	 * @param code
	 * @return
	 * @throws Exception
	 */
	public static final String getJavaI18nResource(Locale locale, String sign, String code) throws Exception{
		if(null == code || "".equals(code))
			return null;

		HashMap signMap = getJavaI18nResource(locale, sign);
		return signMap != null ? (String)signMap.get(code) : null;
	}
```

#### 前端

后端使用 com.ailk.biz.view.handler.I18nResourceHandler 根据 Lang 类中当前的语言标识和传入的资源标识，给前端返回当前界面或组件相关的 JSON 格式的国际化资源内容，代码实现逻辑如下：

```java
public class I18nResourceHandler extends BizHttpHandler
{
	@SuppressWarnings("rawtypes")
	public void init(Writer writer, BaseContext context) throws Exception {
		setContentType("text/javascript");
		String sign = getParameter("sign");
		writer.write("$.lang.extend({");
		try {
			HashMap signMap = I18nUtil.getJsI18nResource(Lang.getLocale(), sign);
			if(signMap != null) {
				String key, value;
				int i = 0, size = signMap.size();
				Iterator it = signMap.keySet().iterator();
				while( size > 0 && it.hasNext() ){
					key = (String)it.next();
					value = (String)signMap.get(key);
					if( key != null && !"".equals(key) ){
						writer.write("\"" + key + "\":\"" + (value == null || "".equals(value.trim()) ? "" : value) + "\"");
					}
					if( i < size -1){
						writer.write(",");
					}
					i ++;
				}
			}
		} catch(Exception e) {
			log.error("Load JsI18nResourceCache Error:", e);
		} 
		writer.write("});");
	}
}
```
