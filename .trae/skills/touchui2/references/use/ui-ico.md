# UI 设计-如何新增图标

## 一、Touch UI 的系统图标
<a href="#/doc/element/ico" target="_blank">Touch UI 的系统图标</a>采用的 iconfont，Chris Coyier 对于 iconfont 如是说：

+ 很容易任意地缩放。
+ 很容易地改变颜色。
+ 可以拥有透明效果。

如果要新增系统图标，可以使用 iconfont 阿里巴巴矢量图标库-这类外部库或者本地 -iconfont 编辑软件，最后新增的 XXX.ttf 以及为了使用字符图标写的 CSS，记得放在自己的工程目录中。
