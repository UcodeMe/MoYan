# 整体居中布局（l_center）
将整体区域固定宽度并居中显示。

## HTML

<a href="#/example/layout/center" target="_blank">查看演示</a>

```html
<div class="c_box-green l_center">
	width:30em，在中间了
</div>
```

## 样式

| 参数名        | 值                                                         | 默认值        | 描述       | 演示       |
| ------------- | ---------------------------------------------------------- | ------------- | ---------- |----- |
| l_center-width-4 | l_center-width-4<br />l_center-width-5<br />l_center-width-6<br />l_center-width-7<br /> l_center-width-8<br />l_center-width-9<br />l_center-width-10<br />   | l_center-width-4 | 宽度设置   |<a href="#/example/layout/center" target="_blank">查看</a>|
