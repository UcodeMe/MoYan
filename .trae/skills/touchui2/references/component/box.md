# 容器（c_box）
可以放置任意组件，一般用于划分区域界限。

## HTML
<a href="#/example/component/box" target="_blank">查看演示</a>						

```html
<div class="c_box"> <!-- 这里放置任意组件 --> </div>
```

## 样式

| 参数名       | 值           | 默认值 | 描述     |演示     |
| ------------ | ------------ | ------ | -------- |---- |
| c_box-border | c_box-border | 无     | 设置边框 |<a href="#/example/component/box-border" target="_blank">查看</a>|
| c_box-rgd-green    | c_box-green</br>c_box-red</br> c_box-blue </br>c_box-orange</br> c_box-navy</br> c_box-gray| 无     | 颜色设置 |<a href="#/example/component/box-color" target="_blank">查看</a>|
| c_box-rgd-green    | c_box-gd-green</br>c_box-gd-red</br> c_box-gd-blue </br>c_box-gd-orange</br> c_box-gd-navy| 无     | 单色渐变 |<a href="#/example/component/box-gdcolor" target="_blank">查看</a>|
| c_box-gd    | c_box-gd-greenBlue</br>c_box-gd-blueRed</br>c_box-gd-redBlue</br>c_box-gd-redOrange</br>c_box-gd-orangeRed   | c_box-gd     | 多色渐变 |<a href="#/example/component/box-gd" target="_blank">查看</a>|
| c_box-r    | c_box-r    | 无     | 设置圆角 |<a href="#/example/component/box-r" target="_blank">查看</a>|
| c_box-border-dashed    | c_box-border-dashed    | 无     | 虚线 |<a href="#/example/component/box-dashed" target="_blank">查看</a>|
