# @Body
将 HTML 文档中的 ``<body>...</body>`` 部分封装成组件，以便工程进行批量维护。


## HTML
```html
<body jwcid="@Body">
	...
</body>
```

## 属性

| 参数名              | 参数类型	|是否必须                  | 默认值 | 描述             |
| ------------------- | ------------------- | ------ | ---------------- |-------- |
| element      | java.lang.String	| 否      | 空     | 元素名，一般可以不写|
