# 段落文本（c_article）
用于显示大篇幅段落文字的区域。 

## HTML
<a href="#/example/component/article" target="_blank">查看演示</a>

```html
<div class="c_article">
	<div class="title">标题</div>
	<div class="subtitle">副标题</div>
	<div class="info">
		<span>作者</span>
		<span>发布时间</span>
	</div>
	<div class="summary">文章摘要</div>
	<div class="content">文章内容<div class="pic"><img src=""/></div></div>
	<div class="aside">文章来源</div>
</div>
```

## 样式

| 参数名              | 值                  | 默认值 | 描述             |演示             |
| ------------------- | ------------------- | ------ | ---------------- |-------- |
| c_article-left      | c_article-left      | 无     | 设置商品详情模式 |<a href="#/example/component/article-left" target="_blank">查看</a>|
| c_article-border    | c_article-border    | 无     | 设置边框         ||
| c_article-nopadding | c_article-nopadding | 无     | 取消边距         ||
| c_article-lite      | c_article-lite      | 无     | 设置轻量版本     |<a href="#/example/component/article-lite" target="_blank"|
