# MoYan

轻量桌面小工具：**剪贴板历史 + 截图标注**，支持 Windows 与 macOS。

![logo](src/assets/logo.svg)

## 功能

### 剪贴板（快捷键 `Shift + C`，可自定义）
- 自动记录复制的**文本**与**图片**（自动去重）
- 顶部搜索框支持内容搜索，可按 全部 / 文本 / 图片 过滤
- 支持固定（Pin）、单条删除、一键清空（固定项保留）
- **单击条目**复制到系统剪贴板；**双击条目**直接粘贴到打开面板前聚焦的输入框
  - Windows：应用启动时用自带 csc 编译的原生小助手（约 30KB）持续记录前台窗口，双击时把该窗口调回前台并模拟 `Ctrl+V`，不依赖焦点自动回落
  - macOS：面板隐藏后向前台应用模拟 `Cmd+V`
- 数据默认存储在 `文档/MoYan`，可在设置中修改存储位置（自动迁移数据）
- 数据过期时间默认 **30 天**，可选 7 / 30 / 90 天或永久，过期自动清理

### 截图（快捷键 `F1`）
- 全屏截图后可拖动**裁剪**区域
- 标注工具：画笔、矩形、椭圆、箭头、文字，支持 5 种颜色、撤销（`Ctrl+Z`）、还原
- **特色功能**：截图下方默认留白说明区，可输入文字说明，导出时自动拼接在图片下方
- 完成后一键复制到剪贴板，或另存为 PNG；所有截图同时归档到存储目录的 `screenshots` 下

### 通用
- 托盘常驻：打开剪贴板 / 截屏 / 设置 / 退出
- 开机自启动可选
- 设置中可自定义两个全局快捷键（点击输入框后按下组合键录制）

## 开发

```bash
npm install      # 安装依赖
npm run dev      # 启动开发模式（Vite + Electron 热重载）
npm run build    # 类型检查 + 构建渲染层与主进程
```

## 打包

```bash
npm run dist:win   # Windows: NSIS 安装包（release/ 目录）
npm run dist:mac   # macOS: DMG（需在 macOS 上执行）
```

应用图标由 `scripts/generate-icons.mjs` 纯 Node 脚本生成（无第三方图像依赖），修改后执行 `npm run build:icons` 重新生成。

## 说明

- 技术栈：Electron 33 + Vue 3 + TypeScript + Vite
- macOS 双击粘贴依赖“辅助功能”权限，截屏需“屏幕录制”权限
- Windows 双击粘贴基于 UI Automation 检测焦点元素，个别应用可能识别不到（此时仅复制）
- 快捷键 `Shift + C` / `F1` 如与其他软件冲突，可在设置中修改
